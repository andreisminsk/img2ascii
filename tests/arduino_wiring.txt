ARDUINO WIRING - LED BLINK
===========================

  Arduino Uno          220Ω         LED
  ┌──────────┐       ┌──┤──┐      ┌──┤──┐
  │          │       │     │      │     │
  │     D13 ─┼───────┤ R1  ├──────┤ A   │
  │          │       └─────┘      │     │
  │     GND ─┼────────────────────┤ K   │
  │          │                    └─────┘
  └──────────┘

  Pin D13  ───── R1(220Ω) ───── LED Anode (+)
  Pin GND  ───────────────────── LED Cathode (-)

  Components:
    R1 = 220Ω resistor
    LED = Red LED
